2. 唇部：双唇轻柔且紧密闭合。
3. 呼吸：气流强制完全经鼻腔进出。

### 条目 2
**标签**: 通用, 神经肌肉再教育, 唇舌肌强化

【口腔肌群康复临床实施与强化标准】
1. 临床处方：定向康复属靶向神经肌肉再教育，需依据脑卒中后遗症、OSA或退行性吞咽障碍等指征制定个性化组合方案。
2. 唇肌静息目标：维持闭唇状态（Lip Seal），防止口腔水分蒸发，构建正确吞咽负压。
3. 强化训练流程：基础定位确立后，采用抗阻、牵伸及负压吸附等高强度动力学训练，促使舌肌纤维肥大、提升张力，以抵抗重力致睡眠气道塌陷并完善高级吞咽功能。

### 条目 3
**标签**: 抿纸, 口面肌功能训练, 呼吸模式矫正

【抿纸训练：标准操作流程与生理目标】
1. 准备：端坐镜前，保持头颈绝对稳定。
2. 定位：选取硬质小纸条，平放于上下唇正中央，贴靠唇红缘内侧。
3. 贴合：上下唇均匀抿紧包裹纸张，微张上下颌，严禁牙齿咬合，力量集中于口轮匝肌。
4. 静力：双唇紧闭维持轻度紧张，持续30-60秒，全程鼻呼吸。
5. 抗阻：轻向外拉拽纸条，唇部提供反向阻力以测试并增强最大收缩力。
6. 循环：放松休息10秒后重复。建议10-15次/组，每日多组练习。
【生理目标】属等长收缩抗阻训练，旨在增强口轮匝肌耐力，建立日间持久闭唇习惯，阻断口呼吸物理通道。

### 条目 4
**标签**: 吸吮抗阻训练, 口面肌功能训练, 构音障碍康复

【吸吮抗阻训练：全流程标准】
【生理目标】模拟吸吮长条状食物，强化口轮匝肌向心收缩力、颊肌内收力及软腭闭合能力，提升气流控制与口腔负压生成。
【准备姿势】端坐于光线充足镜前，保持头部与下巴绝对稳定。
【操作步骤】
1. 定位口型：微张嘴模拟含吸管/面条状，唇微前突嘟嘴，口轮匝肌呈环状收缩。
2. 边缘贴合：双唇向中心收紧留极窄缝隙，严密包裹假想目标物，严防口角漏气。
3. 吸附抽气：双唇紧闭抱红唇吸气，颊肌内收，软腭上抬封闭鼻咽腔，维持口腔强真空负压状态。
4. 瞬间爆破：负压达顶点时瞬间发力发爆破音，下巴保持稳定不晃动，气流冲破双唇阻力发声。
5. 循环频次：连续重复嘟唇吸气与紧唇爆破，每日10-20次/组，规律练习以强化负压生成及构音清晰度。

### 条目 5
**标签**: 纽扣练习, 唇肌抗阻训练, 口面肌功能训练

【纽扣练习：标准操作流程与抗阻规范】
【训练原理】利用细线牵拉纽扣，强制前庭沟区域肌肉（主要为口轮匝肌）进行等长收缩抗阻。
【准备阶段】端坐于光线充足处，面对镜子，保持头颈与下颌绝对稳定。
【执行步骤】
1. 定位置入：取直径2-3cm洁净纽扣，穿系坚韧细线。微张口将纽扣水平置入唇齿间的前庭沟，紧贴牙列外侧。
2. 唇缘闭合：上下唇用力内收完全包裹纽扣，牙齿轻触或留微隙。严禁牙齿咬合纽扣，纯靠唇肌群锁固。
3. 正向抗阻：手持细线向正前方水平缓慢施力，唇部向内收紧对抗，维持最大收缩力20-30秒。
4. 多向抗阻：将拉力方向分别转移至左、右口角，调整唇部发力点抵抗侧向拉力，每侧维持20秒。
5. 循环与进阶：组间放松数秒后重复正/侧向拉拽。建议每日规律训练以增厚口轮匝肌。变体：可双纽扣内外对抗牵拉。

### 条目 6
**标签**: 包棉卷训练, 唇肌抗阻训练, 口面肌功能训练

【包棉卷训练标准流程】
1. 准备：端坐于光线充足镜前，保持头颈绝对稳定。
2. 定位：取医用圆柱形干棉卷，微张口横向置于上下唇间，中心精确对齐唇珠。
3. 包覆：上下唇缘同时向内卷曲压紧，全方位包覆棉卷上下表面，唇红区深度收缩并向内微翻。
4. 施压：禁用牙齿咬合，完全依靠上唇向下极限拉伸与下唇向上托举，将棉卷明显压扁，维持高强度动态夹击10秒。
5. 释放：瞬间松唇使棉卷自然掉落，同步放松咬肌与颈部肌肉，严防异常痉挛代偿。
6. 循环：重复包覆-施压-释放，20次/组，保持频率稳定。
7. 辅助强化：单纯唇部极度拉伸，上唇下拉至极限由下唇压住保持30秒。
【核心机制】该训练物理体积大，要求唇肌具备三维立体包裹控制力，以募集更深层肌肉纤维。

### 条目 7
**标签**: 吹纸练习, 口面肌功能训练, 构音障碍康复

【吹纸练习：标准执行流程】
核心机制：测试并锻炼唇部爆发力，增强软腭抬升与腭咽闭合能力，引导气流经口腔而非鼻腔逸出。
1. 准备姿势：端坐于光线充足的镜子前，保持头部与下巴绝对稳定。
2. 纸张定位：手持轻薄面巾纸或A4纸，垂直悬停于面部正前方5-10厘米处，高度与嘴部齐平。
3. 边缘贴合与蓄气：深吸气后上下唇紧闭，软腭用力向后上方抬起以完全封闭鼻腔通路；气流持续推至口腔前庭，面颊适度鼓起，唇部闭合处严禁漏气，蓄力约2秒。
4. 瞬间爆破：双唇瞬间弹开，快速用力吹气并发“po”音，确保气流精准猛烈击中纸张。
5. 训练量与关联：每次深呼吸后重复10-15次为一组。本练习常与爆破发音、吃面条及吸吮训练联合，靶向改善腭咽闭合不全。
